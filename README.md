# Agent Hub

Windows-ის დესკტოპ აპლიკაცია, საიდანაც **Claude Code**, **Codex** და **Gemini CLI** აგენტებს ერთ ფანჯარაში გაუშვებ.

## ფუნქციები

### 👥 გუნდის ჩატი — სპეციფიკაციიდან production-მდე

ერთ ჩატში წერ დავალებას და მას სამი აგენტის გუნდი ასრულებს:

1. **სპეციფიკაცია** (ნაგულისხმევად Gemini): `docs/specs/<feature>.md`, acceptance criteria-ით
2. ✋ **სპეციფიკაციის დასტური** (შენ)
3. **არქიტექტურა და ტიკეტები** (Claude): `docs/adr/<feature>-plan.md`
4. **გეგმის რევიუ** (Codex): `VERDICT: APPROVE / CHANGES_REQUESTED`; შენიშვნებით ნამუშევარი ავტორს უბრუნდება
5. ✋ **არქიტექტურის დასტური**
6. **იმპლემენტაცია** (Codex): კოდი, ტესტები, მიგრაციები და დოკუმენტაცია
7. 🧪 **ტესტები**: შენი ბრძანება (მაგ. `composer test`); ჩავარდნისას გამოსავალი ავტორს უბრუნდება
8. **კოდის რევიუ** (Claude): რევიუერი diff-ს თავად აპი აწვდის
9. ✋ **გაშვების დასტური**: სურვილისამებრ worktree-დან პროექტში გადატანა

- **ავტორი ≠ რევიუერი:** როლები „⚙ როლები“-ში იცვლება, ხოლო თუ ავტორი და რევიუერი ერთი აგენტია, აპი გაგაფრთხილებს.
- **ციკლი:** მაქსიმუმ 3 ცდა, შემდეგ გადაწყვეტს ადამიანი („მაინც გაგრძელება“ / „დაბრუნება შენიშვნით“ / „გაჩერება“).
- **გადაცემა ფაილით:** ნაბიჯებს შორის კონტექსტი ფაილებით გადაეცემა (spec, ADR), თუ აგენტმა ფაილი თავად არ ჩაწერა, მის პასუხს აპი ჩაწერს.
- **დასტურზე დაბრუნება:** ნებისმიერ დასტურზე შეგიძლია ჩატში შენიშვნა დაწერო და Enter-ით ავტორს დაუბრუნო.
- **იზოლაცია:** git რეპოზიტორიაში ყველაფერი ცალკე worktree-ში ხდება, პროექტი კი მხოლოდ საბოლოო დასტურის შემდეგ იცვლება.

### სხვა

- **ჩატი** — აგენტი ფონზე მუშაობს (`claude -p`, `codex exec`, `gemini -p` JSON რეჟიმში), პასუხები ჩანს ჩატად: ტექსტი Markdown-ით, ხელსაწყოების გამოძახებები (ფაილის წაკითხვა, ბრძანებები, რედაქტირება) ჩამოშლად ბლოკებად, ტოკენები და ფასი
- **ისტორია და ძიება** — ყველა ჩატი ინახება; გვერდით პანელში ჩანს მიმდინარე პროექტის ჩატები, ძიება ეძებს ყველა საუბარში; ძველ ჩატს ხსნი და აგრძელებ (აგენტის `--resume`-ით)
- **ექსპორტი** — ჩატი ან ტერმინალის ლოგი Markdown ფაილად
- **ფაილების drag & drop** — ჩატში ემატება `@path` სახით, ტერმინალში — ბილიკად
- **პრომპტის შაბლონები** — იმართება პარამეტრებში, ჩაისმება ჩატში ან ტერმინალში
- **ავტო-დადასტურება** ჩატისთვის (გამორთულზე მხოლოდ ფაილების რედაქტირებაა ნებადართული)
- **ყველა აგენტი ერთად (შედარება)** — ერთი პრომპტი რამდენიმე აგენტს, პასუხები სვეტებად გვერდიგვერდ; „★ საუკეთესო“ პასუხის მონიშვნა და სტატისტიკა (პარამეტრებში)
- **Git worktree იზოლაცია** — შედარებისას (და სურვილისამებრ ჩვეულებრივ ჩატშიც) თითოეული აგენტი მუშაობს პროექტის ცალკე ასლში საკუთარ ბრენჩზე (`~/.agenthub/worktrees`)
- **Diff ხედი** — რა შეცვალა აგენტმა: ფაილების სია +/− სტატისტიკით და ფერადი diff; worktree-დან „პროექტში გადატანა“ (commit-ის გარეშე) და worktree-ის წაშლა
- **Split view** — 1, 2 ან 4 (2×2) პანელი ერთდროულად; ტაბ-ბარის მარჯვენა კუთხეში
- **ჯაჭვი (pipeline)** — აგენტები რიგრიგობით (მაგ. Gemini გეგმავს → Claude წერს → Codex ამოწმებს); თითოეული ნაბიჯი იღებს დავალებას და წინა ნაბიჯის პასუხს; ჯაჭვები ინახება შაბლონებად; სურვილისამებრ ცალკე worktree-ში
- **ხარჯი** — ფასი და ტოკენები აგენტების მიხედვით: დღეს / 7 დღე / 30 დღე / სულ (ჩატებიდან)
- **MCP სერვერები** — ერთ ცხრილში სამივე აგენტის MCP სერვერები; დამატება ერთდროულად რამდენიმე აგენტში, ან ✓/+ ღილაკით ცალკეულში (Claude: `~/.claude.json`, Gemini: `~/.gemini/settings.json`, Codex: `codex mcp`)
- **ინსტრუქციები** — CLAUDE.md / AGENTS.md / GEMINI.md ერთ რედაქტორში; ჩანს რომელი ემთხვევა და რომელი არა, ერთი ღილაკით სინქრონიზაცია
- **შეტყობინებები** — Windows-ის შეტყობინება, როცა აპი ფონზეა და ჩატი / შედარება / ჯაჭვი დასრულდა, ან ტერმინალში აგენტი ყურადღებას ითხოვს
- **ყველას განახლება** — ინსტალაციის ცხრილში ერთი ღილაკით ყველა მოძველებული აგენტის განახლება
- აგენტის გაშვება ჩაშენებულ ტერმინალში (xterm.js + ConPTY)
- ტაბები და პარალელური სესიები; შუა ღილაკით დაკლიკება ტაბს ხურავს
- პროექტის ფოლდერის არჩევა და ბოლო პროექტების სია
- ინსტალაციის შემოწმება: აჩვენებს თითოეული CLI-ის ვერსიას და npm-ის ბოლო ვერსიას; „განახლება“ აქტიურია მხოლოდ მაშინ, როცა ახალი ვერსია არსებობს. Node.js-ის დაყენება winget-ით
- API გასაღებები, რომლებიც Windows DPAPI-ით დაშიფრული ინახება და აგენტს გარემოს ცვლადად გადაეცემა
- დამატებითი არგუმენტები თითოეული აგენტისთვის
- ქართული და ინგლისური ინტერფეისი
- Ctrl+C კოპირებს მონიშნულ ტექსტს, Ctrl+V აკოპირებს ტერმინალში

## ინსტალაცია და განახლება

ჩამოტვირთე `AgentHub-Setup-x.y.z.exe` [Releases](https://github.com/ITGuka/agent-hub/releases/latest)-დან და ერთხელ დააყენე.
ამის შემდეგ აპი ახალ ვერსიას თავად ამოწმებს: გაშვებისას, ყოველ 30 წუთში და ფანჯარაზე დაბრუნებისას, ან ხელით
**პარამეტრები → ვერსია → განახლების შემოწმება**. როცა ახალი ვერსია გამოვა, გვერდით პანელში გამოჩნდება
**ჩამოტვირთვა → გადატვირთვა და განახლება**.

### რელიზის გამოშვება

ასწიე `version` `package.json`-ში და დაპუშე `main`-ზე. GitHub Actions-ი ააწყობს ინსტალერს და
გამოაქვეყნებს რელიზს `v<version>`.

აგენტების დასაყენებლად საჭიროა [Node.js](https://nodejs.org) 20+.

## დეველოპმენტი

```bash
npm install
npm run dev     # დეველოპმენტის რეჟიმი
npm run dist    # Windows-ის ინსტალერი dist/-ში
```
